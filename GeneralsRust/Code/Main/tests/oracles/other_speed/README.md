# Normal OTHER scheduled speed regression

The public `tests/other_speed.rs` covers thirteen immutable original-backed scenarios through the authored loader, Worker-only object admission, public pose/velocity/move setup, and one scheduled fixed tick. It distinguishes the signed component-product speed metric from ordinary dot projection, and independently distinguishes the entry sample from a sample after rotation. Cached entry force direction remains a separate obligation. The rested slide is only an unchanged-direction sentinel; nonzero slide speed is outside this slice.

## Original authority and replay

`source-pins.json` pins six original files and every extracted block. The generator executes unchanged `Locomotor.cpp:2326–2404` (OTHER), `PhysicsUpdate.cpp:939–957` (signed forward speed), force/motive helpers, coordinate normalization, frame conversion and velocity-add statements. The original OTHER scalar is sampled before rotation and retained for force. Magnitude is the square root of the sum of squared component products; the sign comes from their sum, with zero selecting positive. Rotation outputs, body, clock, mass and template access are explicitly labelled harness providers. Original scheduler, full rotation, terrain, collision, friction and whole-frame trajectory do not execute in the extraction.

From this directory run `python3 generate_other_speed_oracle.py --output /tmp/new-other-speed-replay`, then `python3 verify_other_speed_oracle.py --run /tmp/new-other-speed-replay`. Both require a new output directory and the installed C++17 compiler; no download or Cargo is used. A source-only package can pass `--source-root <root>` containing the six exact pinned original paths. The default source root is this checkout. Source-file, block and manifest drift fail before compilation.

The fixture is `../../fixtures/other_speed_original.txt`, SHA-256 `8d1119310807f7d3abb1a781059888690629f5ba01e87cc6febf778b778188ef`. Its 26 rows use distinct raw-frame and host-impulse adapters; `fixture-schema.json` describes the 47 fields. The host adapter uses explicit prior host velocity, parsed/rebound host speed, and acceleration/braking times dt. Original XYZ maps to host `(X,Z,-Y)`. Projected displacement is labelled diagnostic, not original-engine position evidence. Supplied headings never come from candidate force or motion.

A nonturning diagonal distinguishes original speed 30 from dot 42.4264, reversing acceleration/braking at goal 36. The independent axis-input 30-degree turn distinguishes entry speed 30 from late speed 25.9808 at goal 27: original X impulse is -2.999998093, late sampling gives +1.019239426. Reflected cases, cancelling component products, negative diagonal and axis clamps, 90-degree and negative-speed turns, a masking diagonal-to-axis turn, a rested turn and a rested slide bound the selected behavior. Approach stays enabled but all selected goals exceed its slowdown distance.

The three labelled diagnostic mutations alter entry metric only, sample timing only, or both, while retaining original force direction. They change respectively 10, 8 and 16 force rows. Axis, negative-axis, rested turn and rested slide controls remain identical. The masking case would reject an incomplete entry-dot repair even though the current late-dot output coincides with original. Mutations are not original evidence. Verification requires byte-identical original fixture replay and all orthogonal control outcomes.

## Public measurement and limits

The test starts with an empty warm tick so the measured movement is due. It verifies pristine admission, mass one, authored parser/binding bits, no locomotor-field repair, no authoritative shadow coupling, no path/worker/weapon/containment/collision writers, no pivot/wander/reverse/braking/stun/freefall/held state, and unchanged nonzero entry velocity through `move_to`. Cancellation explicitly selects positive 30 despite zero sign sum, while negative cases retain -30. The approach margin is independently guarded.

Entry values, requested normalized heading, scalar inputs, and the observed output yaw/direction are recorded before production changes, then matched exactly in baseline/candidate evidence. Fixed tolerances against the separately supplied original headings allow pre-existing matrix/trigonometric differences; force never generates a heading expectation.

Default lateral friction and public ultra-accurate extra friction stay active. Under the asserted no-other-writer guards, final XZ velocity minus `previous_acceleration` reconstructs marched velocity; subtracting entry velocity isolates impulse. Both marched velocity and impulse are compared with frozen original host rows. Lateral friction is separately checked, and actual XZ displacement must equal marched velocity times dt. The force tolerance is 3e-5 and position tolerance 2e-5 host units; Y is not reconstructed. This is bounded force-stage evidence, not original whole-frame or full-trajectory parity.

The production scope is normal non-slide OTHER. TWO_LEGS, Hover, Wings, Treads, Climber, Wheels, nonzero slide semantics, persistent state, serialization and ownership remain outside this correction.
