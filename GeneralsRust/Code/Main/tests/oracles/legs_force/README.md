# TWO_LEGS scheduled force regression

The public `tests/legs_force.rs` exercises loader, synthetic Worker-only admission, ordinary host authority, and an actual scheduled fixed tick. The fixture executes unchanged original `moveTowardsPositionLegs`, `getForwardSpeed2D`, force and motive helpers, and Euler velocity statements with explicitly supplied directions. It is an extracted force stage, not the original game or an original rotation/trajectory oracle.

The five source files and fourteen extracted blocks are SHA-256 pinned in `source-pins.json`; the generator rejects changed pins or original bytes before compiling. Original bodies retain line directives. Rotation, object accessors and mass-one state are labelled harness stubs. Rotation records the requested angle and installs a supplied heading/direction. Width and minimum speed are zero, health is pristine, approach slowdown is disabled, and no dispatcher, terrain, collision, friction, gravity, RNG or save/load executes in the C++ harness.

## Reproduce

From this directory, run `python3 generate_force_oracle.py --output /tmp/legs-force-oracle`, then `python3 verify_oracle.py --run /tmp/legs-force-oracle`. The default source root is the containing repository. A standalone copy may supply `--source-root <root>` containing the five pinned files. Only the existing `/usr/bin/c++` is used with `-std=c++17 -O0 -ffp-contract=off -fno-fast-math`. Output includes exact extracted bytes, original and labelled diagnostic sources/binaries, compiler commands and hashes, and control verification.

The immutable fixture is `../../fixtures/legs_force_original.txt`, SHA-256 `230a3e6011aeda7e66fd52a7982721c71efabe692b76669ff1175a2bfe61cb83`. Its 24 rows comprise eight raw-frame rows, eight host-impulse adapter rows, and eight exact-frame clamp controls. Diagnostic dot-speed mutation changes ten force rows; late sampling changes four. Axis force remains positive and unchanged. Those counts are scalar controls, not Main tests.

## Representation boundary

Original XYZ maps to host `(X,Z,-Y)`. Raw-frame velocity, speed and rates use the original seconds-to-frame conversion functions. The host adapter takes runtime velocity as host units, rebinds template speed by 30 and acceleration/braking by 30 twice, then multiplies rate by fixed `1/30` for the original force stage. Exact-frame rows bypass conversion to preserve strict signed clamp equality. Raw-frame output scaled by 30 can differ from the adapter by f32 rounding; it is deliberately not substituted for the adapter. Every numeric fixture scalar is hexadecimal f32.

The public test checks parser and binding bits, admission, entry velocity/yaw/direction/signed scalar, no active shadow, frame/step count, gate passage, surviving target, and no alternate velocity writers. Targets are distant so ordinary approach braking does not trigger. The baseline public turn output must be observed and frozen before the production force consumer is changed. Expected force direction and velocity always come from the previously frozen original fixture, never candidate motion. The independent heading test runs before force comparison and must stay unchanged. Mat4 yaw recovery, target normalization and reconstructed rotation targets can differ from original atan2/cosf/sinf by a few ULPs; the narrow tolerances are 2e-6 for yaw/direction and 3e-5 for host marched velocity, with the smallest baseline distinguishing component gap greater than 0.98 host speed units (more than 32,900 times the velocity tolerance). The distinguishing projected-impulse gaps exceed one unit.

Later lateral friction remains enabled and uses its own correct dot decomposition. The public test checks that separate contribution, requires it to be nonzero for turning/cancellation, reconstructs marched XZ velocity as final velocity minus previous acceleration, and compares against original adapted integrated velocity columns 24-26. It checks XZ displacement equals marched velocity times dt. Y is not reconstructed, and this does not claim full original post-friction pose parity. Axis, diagonal/reflection, cancellation, reverse clamp and two independently frozen turn controls exercise the bounded force correction. Existing infantry, approach, signed-braking, braking-representation and airborne tests are adjacent controls.
